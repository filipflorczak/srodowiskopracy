# Remote Work Helper - Projekt Aplikacji do Zarządzania Energią

System wspierający produktywność i dobrostan pracowników zdalnych poprzez inteligentne zarządzanie przerwami i sesjami głębokiej pracy.

## 📌 O projekcie
Aplikacja ma na celu rozwiązanie problemu zacierania się granic między pracą a odpoczynkiem (work-life blend) oraz przeciwdziałanie cyfrowemu zmęczeniu. Wykorzystuje techniki interwałowe, aby dbać o zdrowie fizyczne i psychiczne użytkownika w trakcie dnia pracy.

## 🚀 Kluczowe Funkcje
- **Inteligentny Timer:** Adaptacyjne sesje pracy oparte o metodę Pomodoro.
- **Biblioteka Przerw:** Zestaw szybkich ćwiczeń relaksacyjnych i fizycznych.
- **Statystyki Energii:** Śledzenie korelacji między regularnością przerw a wydajnością.
- **Tryb Focus:** Minimalistyczny interfejs ograniczający rozpraszacze.

## 🛠️ Technologie (Planowane)
- **Frontend:** React Native / Flutter (aplikacja mobilna)
- **Logika:** JavaScript/TypeScript
- **Dokumentacja:** Markdown & Mermaid
